# VideoScreen for NeoForge 26.2

Local MP4 playback on automatically merging Minecraft screen blocks.

## Controls
- Place Video Screen blocks in a rectangle on a wall.
- Right click any screen block to choose a local MP4.
- Shift + right click any screen block to pause/resume.
- Video is mapped across the entire connected panel.
- Current prototype decodes video only; audio is not yet implemented.

Target: Minecraft 26.2 / NeoForge 26.2.0.87 / Java 25.
